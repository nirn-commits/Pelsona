# Pelsona

LLM の API を使って、自分で設定したキャラクターとチャットできる Web アプリです。ビルド不要、静的ファイル 3 つ (`index.html` / `styles.css` / `app.js`) だけで動きます。

## 主な機能

- **4 つのキャラクタースロット** (左端=自分)。クリックで選択、複数選択でグループ会話。
- **キャラ画像** (ローカル画像をアップロード、長辺 512px に自動縮小して保存)
- **キャラ設定 / 口調 / 最初の一言** を個別に登録
- **プリセット機能**: キャラ設定をライブラリに保存し、任意のスロットに読込
- **チャット保存機能**: 複数の会話を名前付きで保存、いつでも切替・改名・削除
- **世界観設定 (全チャット共通)**: すべてのチャットのシステムプロンプトに挿入
- **シチュエーション設定 (チャット個別)**: そのチャットだけの場面・状況を設定
- **引き継ぎメモ**: 前の会話からあらすじを書き写して話の流れを継承可能
- **Google Gemini / Anthropic Claude / OpenAI 互換 API** に対応
- すべての設定・会話は **ブラウザの localStorage** に保存

## 起動

`index.html` をブラウザで開くだけです。
ローカルサーバを立てる場合:

```bash
python3 -m http.server 8000
# -> http://localhost:8000
```

## 使い方

1. 右上の「☰」メニュー → **⚙ API** タブで API を設定
   - **Gemini**: [Google AI Studio](https://aistudio.google.com/apikey) でキー取得。モデル例: `gemini-2.5-flash` / `gemini-2.5-pro`
   - **Anthropic**: モデル例: `claude-opus-4-7`
   - **OpenAI 互換**: エンドポイント + モデル名を設定 (例: LM Studio なら `http://localhost:1234/v1`)
2. (任意) **🌍 世界観** タブで全チャット共通の世界観を登録
3. 下部スロットをクリックしてキャラを設定 (画像・名前・人格・口調・最初の一言)
4. キャラ編集画面で **「💾 プリセットに保存」** でライブラリに登録可能。他のチャット/スロットから **「📚 プリセットから読込」** で呼び出せます
5. 非自分スロットをクリックで選択 → 入力欄からメッセージ送信
6. 画面上部のチャット名をクリックすると **シチュエーション** と **引き継ぎメモ** を編集できます
7. 「☰」メニュー → **💬 チャット** タブから **＋ 新しい会話** で別チャット作成
   - 作成時に「現在のスロットを引き継ぐ」「現在の会話の末尾を引用」が選べます

## システムプロンプトの構成

実際に LLM に渡るシステムプロンプトは以下の順で組み立てられます (空セクションは省略):

```
# 世界観 (全チャット共通)
...

# 今回のシチュエーション (そのチャット限定)
...

# 前回までの流れ (引き継ぎメモ)
...

# 演じるキャラクター
名前 / 人格 / 口調 ...

# 応答ルール (複数キャラ時のみ)
- [キャラ名] セリフ の形式で返答
```

## データ構造 (localStorage キー)

| キー | 内容 |
| --- | --- |
| `pelsona.chats.v1` | チャット配列 (各チャットに slots / history / situation / carryover) |
| `pelsona.current.v1` | 現在表示中のチャット ID |
| `pelsona.presets.v1` | キャラプリセット配列 |
| `pelsona.world.v1` | 世界観設定 |
| `pelsona.api.v1` | API 設定 |
| `pelsona.chars.v1` / `pelsona.history.v1` | 旧バージョン。起動時に最初のチャットへ自動移行 |

## セキュリティ上の注意

- API キーは localStorage に平文で保存されます。共有端末での利用は避けてください。
- Gemini / Anthropic / OpenAI いずれもブラウザから直接 API を叩きます (Anthropic は `anthropic-dangerous-direct-browser-access: true`)。本番用途では API キーを隠すバックエンドプロキシを推奨。
- 画像は data URL で localStorage に保存されるため、大量・大容量画像はストレージ容量を圧迫します。
